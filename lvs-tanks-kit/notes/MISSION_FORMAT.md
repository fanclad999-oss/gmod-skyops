# Миссии SkyOps

Миссия — обычная Lua-таблица в `lua/skyops/missions/sv_<id>.lua`, которая вызывает
`SkyOps.Missions.Register{ ... }`. Логики в файле миссии нет: движок
(`lua/skyops/mission/`) читает таблицу, через ядро спавнит самолёты и ПВО, следит за
задачами и шлёт игрокам брифинг, прогресс и итоги.

**Все расстояния и высоты в файлах миссий в метрах, скорость в км/ч.**

## Как запустить

| Команда | Что делает |
|---|---|
| `skyops_missions` | меню выбора миссии (для админа) |
| `skyops_mission_start <id>` | начать брифинг миссии |
| `skyops_mission_launch` | вылет сразу, не дожидаясь готовности |
| `skyops_mission_restart` | перезапустить текущую миссию |
| `skyops_mission_abort` | прервать миссию и убрать всё созданное |
| `skyops_briefing` | снова открыть свёрнутый брифинг |
| `skyops_anchor_here <имя>` | напечатать в консоль якорь карты в текущей точке |

Брифинг длится `skyops_brief_time` секунд (120). Когда все занявшие места нажали
«Готов к вылету», через `skyops_launch_delay` (5 с) экипажи оказываются в самолётах.

## Якоря карты

Миссии не знают координат: они ссылаются на именованные якоря из
`lua/skyops/maps/sh_<карта>.lua` (`airfield_main`, `hill_214`, ...). Якорь регистрируется
через `SkyOps.Map.Register( name, { chunk, pos, ang } )` ядра. Сейчас у Кировского все
якоря примерные (`todo = true`), их нужно снять в игре командой `skyops_anchor_here`.
Там же лежат маршруты (`routes`) для колонн, направление на север и уровень моря.

## Поля миссии

| Поле | Что это |
|---|---|
| `id`, `name`, `type` | ID, название, тип для брифинга: `strike`, `recon`, `sead`, `intercept` |
| `map` | ключ карты |
| `briefing` | `situation` (текст обстановки), `time`, `weather` |
| `aircraft` | `{ role, crew, loadout_text }`: роль из `SkyOps.Registry.Aircraft`, мест в экипаже, подвеска для брифинга |
| `flights` | сколько экипажей можно (по умолчанию 2) |
| `callsign` | позывной звена (по умолчанию «Гром»: Гром-1, Гром-2) |
| `start` | `anchor`, `airborne`, `alt` (м над уровнем моря), `speed` (км/ч) |
| `waypoints` | `{ id, anchor, radius, label }` |
| `units` | что спавнить, см. ниже |
| `objectives` | задачи, порядок = порядок в брифинге |
| `fail` | `crew_dead` (по умолчанию да), `time_limit` (с) |
| `score` | очки за задачи по их id, `per_kill`, пороги оценок `grades = { S, A, B, C }` |
| `radio` | `{ start = "..." }`, а у задачи — поле `radio` с фразой при выполнении |

### Юниты (`units`)

| `kind` | Поля | Через что спавнится |
|---|---|---|
| `airdefense` | `system` (s75, tor_m1, osa, roland, aaa), `anchor`, `part`, `follow` | `SkyOps.Spawn.AirDefense` |
| `convoy` | `class`, `count`, `route` | `SkyOps.Spawn.Convoy` |
| `aiflight` | `role`, `count`, `anchor`, `task`, `team` | `SkyOps.Spawn.AIFlight` |
| `static` | `class`, `anchor` | `ents.Create` |

`part` — часть комплекса: у С-75 это `snr75`, `launcher`, `p12_radar`. Комплекс спавнится
один раз на якорь, а группы собираются из его частей по классу в радиусе 400 м.
`briefing = true` показывает юнит на карте брифинга и в списке угроз (с радиусом поражения).

### Задачи (`objectives`)

| `type` | Параметры | Выполнена, когда |
|---|---|---|
| `reach` | `waypoint`, `max_alt`, `min_alt`, `alt_ref` | самолёт вошёл в радиус WP в коридоре высот |
| `destroy` | `unit`, `count` | уничтожено ≥ `count` объектов группы (без `count` — все) |
| `recon` | `waypoint`, `max_alt`, `time` | набрал `time` секунд над WP ниже `max_alt` |
| `land` | `anchor`, `radius` | самолёт стоит на земле у якоря, скорость < 10 км/ч |
| `protect` | `unit`, `max_lost` | провал, если группа потеряла больше `max_lost` |
| `defend` | `unit`, `anchor`, `radius` | провал, если юнит группы вошёл в радиус; выполнена, когда группа уничтожена |
| `survive` | `time` | продержаться `time` секунд |

Высоты по умолчанию считаются над землёй (`alt_ref = "agl"`), `alt_ref = "msl"` — над
уровнем моря. Общие поля: `id`, `text`, `optional` (дополнительная, не нужна для успеха),
`after` (id задачи выше по списку, после которой эта становится активной).

Миссия успешна, когда выполнены все обязательные задачи. Провал: обязательная задача
провалена, потеряны все самолёты или вышло время.

## Обмен с клиентом

| Сообщение | Направление | Содержимое |
|---|---|---|
| `skyops_brief` | S→C | брифинг: тексты, WP и угрозы с мировыми позициями, самолёты |
| `skyops_lobby` | S→C | звенья, кто на каком месте, готовность, таймеры |
| `skyops_slot` / `skyops_ready` | C→S | занять место / готовность |
| `skyops_state` | S→C | состояние: 0 нет, 1 брифинг, 2 полёт, 3 итоги |
| `skyops_obj` | S→C | состояние и прогресс задач |
| `skyops_msg` | S→C | радиосообщение (отправитель, текст) |
| `skyops_debrief` | S→C | итоги: задачи, очки, оценка, экипажи |
| `skyops_sync` | C→S | запрос всего состояния при входе |
| `skyops_rwr` | S→C | от ядра: облучение РЛС ПВО (см. docs/ui.md) |

Хуки: `SkyOps.MissionStart( def, run )`, `SkyOps.ObjectiveChanged( obj, run )`,
`SkyOps.MissionEnd( debrief, run )`. Уничтожения движок берёт из `SkyOps.UnitKilled` ядра.
