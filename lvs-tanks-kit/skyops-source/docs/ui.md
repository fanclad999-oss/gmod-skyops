# Интерфейс SkyOps

Свой HUD заменяет стоковый HUD LVS на самолётах из `SkyOps.Registry.Aircraft`. Хук LVS
`!!!!!LVS_hud` обёрнут: на наших самолётах он молчит, на остальной технике работает как
раньше. Оверлеи оружия LVS (прицелы, FLIR штурмана) остаются (`skyops_hud_stockweapons`).

## Две школы символики

| | Су-34, Су-25СМ3 (`ru`) | Tornado IDS, F-14A (`nato`) |
|---|---|---|
| Скорость | приборная, км/ч | приборная, узлы |
| Высота | барометрическая, м; радиовысота «Р» ниже 1500 м | футы; «R» ниже 5000 ft |
| Вертикальная скорость | Vy, м/с | VV, ft/min |
| Символ оси | «самолётик» | ватерлиния W |
| Лестница тангажа | через 10°, числа справа | через 5°, числа с двух сторон |
| Режимы | НАВ / БОМБ / В-В | NAV / CCIP / A-A |
| ППМ | ППМ, км | STPT, NM |

Приборная скорость и число Маха считаются по стандартной атмосфере от истинной скорости
и высоты. Перегрузка считается из ускорения самолёта. У F-14 дополнительно угол атаки.

Горизонт, лестница тангажа, вектор скорости, ромб ППМ и марка CCIP **конформны**: это
проекция направлений в мире на экран, поэтому они совпадают с настоящим горизонтом и
целью и в кабине, и с внешней камеры. Скорость, высота и шкала курса стоят в рамке HUD
вокруг оси самолёта.

**CCIP** (режим БОМБ / CCIP): точка падения при сбросе сейчас. Бомбы LVS летят без
сопротивления воздуха, поэтому баллистика точная: скорость самолёта + гравитация, шаг
0.1 с, трасса до земли. Если марка ушла под нижний край HUD, показывается «ЖДИ / DELAY».

Режим включается по выбранному оружию (по иконке), вручную: `skyops_hud_mode`.

## Штурман-оператор / оператор РЛС

Справа внизу МФИ «курс вверх»: маршрут, ППМ, зоны ПВО и цели из брифинга, свои самолёты.
Слева большой индикатор СПО, сверху повторитель скорости, высоты, М и перегрузки.

| Команда | Что делает |
|---|---|
| `skyops_mfd` | скрыть / показать МФИ (например, чтобы смотреть в FLIR) |
| `skyops_mfd_zoom` | масштаб 10 / 20 / 40 / 80 км |

## СПО (RWR)

Круг, нос вверх, чем ближе к центру, тем опаснее. Обозначения: русская школа (`75`, `ТР`,
`ОС`, `РЛ`, `А`, `И`) и NATO (`2`, `15`, `8`, `RO`, `A`, `F`). Рамка — сопровождение, мигание
и кружок — пуск. У пилота маленький индикатор слева внизу (`skyops_hud_rwr`).

Источники: сообщение ядра `skyops_rwr`, а пока его нет — видимые клиенту ПВО и
истребители противника по дальности. Ракета на нас определяется по направлению и
скорости, поэтому работает и для ракет SW Bombs, и для `lvs_missile`.

Формат `skyops_rwr` (ядро шлёт экипажу раз в 0.5–1 с):

```
UInt(8) N
N раз: Vector мировая позиция РЛС, String система (s75, tor_m1, ...), UInt(2) состояние 0 поиск / 1 сопровождение / 2 пуск
```

## Настройки игрока

| ConVar | По умолчанию | |
|---|---|---|
| `skyops_hud` | 1 | свой HUD вместо стокового |
| `skyops_hud_color` | green | green, amber, cyan, white |
| `skyops_hud_brightness` | 1 | яркость символики 0.3..1 |
| `skyops_hud_shadow` | 1 | тёмная подложка под символикой |
| `skyops_hud_objectives` | 1 | список задач и радио |
| `skyops_hud_any` | 0 | рисовать HUD на любых самолётах LVS |

Шрифты: Bahnschrift и Consolas (есть в Windows 10/11), отдельно их ставить не нужно.
