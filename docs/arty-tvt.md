# Режим команда на команду (arty/tvt)

Две команды, у каждой своя 2С35, дрон и КамАЗ. Одна команда не видит меток, целей,
координат, подсветки и радио другой. Выключено (`skyops_tvt 0`, по умолчанию) — всё как
раньше: одиночная игра и кооператив без изменений.

## Как играть

1. Хост: `skyops_tvt 1`. Игроки сразу получают команду (в меньшую), в чате подсказка.
2. Сменить команду: `!синие`, `!красные`, `!команда` (меню), консоль `skyops_team 1|2|auto`.
3. Своя техника: `!комплект` (раз в 60 с) ставит 2С35 впереди и КамАЗ с дронами справа.
   Технику из меню спавна тоже можно брать: она получает команду того, кто её создал.
4. Справа вверху плашка «Команда: Синие» (`skyops_tvt_hud 0` — скрыть).

## Что скрыто от другой команды

| Что | Где | Как |
|---|---|---|
| САУ и дроны на карте планшета, круг барража, точка камеры, пятно подсветки | ui/cl_api (`A.Visible`, `A.AllDrones`), ui/cl_map | рисуются только свои |
| «Своя» САУ по близости (вычислитель, HUD дрона) | ui/cl_api `A.MySPG` | чужая не выбирается |
| Координаты с дрона (T) | drone/sv_laser `D.SendTarget` | `net.Send` своей команде |
| Разрывы на планшете и в вычислителе | core/sv_ballistics `Impact` | `net.Send` команде САУ |
| Краснополь на подсветку | drone/sv_guided, `D.LaserSpots( viewer )` | только подсветка своей команды |
| Пересадка в дрон (U), выбор дрона | drone/sv_switch | только свои дроны |
| Задание: цели, район, ОП, радио | missions/sv_missions | задание принадлежит команде ведущего, другая видит «нет задания», не может войти, прервать или начать своё поверх |
| Контрбатарея | counter/sv_counter | в режиме только во время задания; радио, «прилёт», батарея — команде САУ |
| Подвоз БК, выгрузка дрона (O) | supply/sv_supply, sv_kit, cl_supply | только из своего КамАЗа |
| Чужая техника | arty/tvt/sv_tvt | нельзя сесть и взять пульт (`skyops_tvt_lock 0` — можно) |

Видно всем, как и в жизни: выстрелы, полёт снаряда, разрывы и дым в мире, ветер.

## API (core/sh_teams.lua)

- `SkyOps.Teams.TvT()` — режим включён.
- `SkyOps.Teams.Of( ent )` — команда игрока или техники, 0 = нейтральная. Кресло, пульт
  дрона (`NWEntity UAV`) и прочие части берут команду корпуса. Хранится в `NW2Int SkyOps_Team`.
- `SkyOps.Teams.Friendly( a, b )` — одна команда, одна из них нейтральная или режим выключен.
- `SkyOps.Teams.CanSee( ply, ent )` — может ли игрок видеть метки техники (игрок без
  команды в режиме видит только нейтральное).
- `SkyOps.Teams.Recipients( team | ent )` — кому слать: всем, если режим выключен или
  команда 0.
- Сервер: `SkyOps.Teams.Set( ent, team )`, `SkyOps.Teams.Claim( ent, ply )` (пометить,
  если ещё без команды), `SkyOps.Teams.Join( ply, team )`, `SkyOps.Teams.GiveKit( ply )`.
- Хук `SkyOps.TeamChanged( ply, team, old )`.

Команду технике ставят: спавн из меню (`PlayerSpawnedSENT`), создатель (`SetCreator` /
`CPPISetOwner`, так делают вылет дрона и катапульта КамАЗа), комплект задания, посадка в
технику без команды. В режиме технике ставится и `SetAITEAM`, игроку — `lvsSetAITeam`.

## Консоль

| Переменная | По умолчанию | |
|---|---|---|
| `skyops_tvt` | 0 | 1 = команда на команду |
| `skyops_tvt_lock` | 1 | нельзя садиться в чужую технику |
| `skyops_tvt_kit` | 1 | разрешить `!комплект` |
| `skyops_tvt_hud` (клиент) | 1 | плашка команды |
