# Артиллерия: задания (`lua/skyops/arty/missions/`)

Одно задание на сервер, для 1–2 игроков. Работает поверх `arty/core` (сетка, баллистика,
САУ) и, если он есть, модуля дрона. Движок самолётных миссий SkyOps (`mission/`) не
используется: там всё завязано на экипажи самолётов и вылет с брифинга.

| Файл | Что делает |
|---|---|
| `sh_missions.lua` | типы заданий, дальности, виды целей, модель поражения, оценки, общие функции |
| `sv_targets.lua` | поиск ровного места на рельефе, спавн замороженных целей, разрывы по целям, уход скоротечной цели |
| `sv_missions.lua` | этапы задания, генерация ОП и цели, учёт выстрелов, доклады о разрывах, итоги и очки, команды |
| `cl_missions.lua` | меню (F7, `!arty`), HUD задания, стрелка-компас на точку, радио, метки на карте планшета, итоги с картой разрывов |

## Как играть

1. F7 (или `!arty` в чате, или `skyops_arty_missions`) → тип, дальность, «марш на ОП», «выдать технику» → «Начать».
2. **Марш**: доехать на 2С35 до круга ОП (радиус 150 м), координаты и стрелка на экране.
3. **Развёртывание**: H на ОП.
4. **Цель**: штаб присылает координаты через `skyops_arty_mission_hq_delay` с (20) с ошибкой
   (`hqError`, только в хардкоре), либо дрон находит цель в районе поиска: захват камерой
   (стоковый `TrackPos`) ближе 80 м от цели в течение 3 с или «передать» модуля дрона.
   Координаты уходят в вычислитель через `skyops_arty_target`.
5. **Огонь**: каждый разрыв снаряда орудия задания судится по своей модели поражения.
   Дрон ближе 7 км к разрыву (или кто угодно в авто) докладывает «правее 40, дальше 120».
6. **Итоги**: оценка S–D, очки по пунктам, время этапов, промахи, карта разрывов.
   История в `data/skyops/arty_missions.json`.

Второй игрок жмёт «Присоединиться» в меню. Орудие задания: САУ, в которой сидит участник
при старте (или ближайшая в 100 м), иначе первая, в которую он сядет или из которой выстрелит.

## Типы

| id | Название | Цель | БК |
|---|---|---|---|
| `raid` | Огневой налёт | 5 машин, координаты штаба ±60 м | ОФС 24 |
| `recon` | Цель по дрону | батарея 3 орудия + 2 машины, район 500 м | ОФС 20, Кр 2 |
| `laser` | Краснополь по подсветке | КП (тяжёлая броня, обязателен) + машина, район 400 м | Кр 4 |
| `fleeting` | Скоротечная цель | 6 машин, через 4:00 после обнаружения уходят на 400–700 м | ОФС 30, Кр 2 |

Дальности: близко 4–8 км, средне 8–15, далеко 15–24. Если карта мала, полоса ужимается.

## Модель поражения

Цели не получают урон движка (`EntityTakeDamage` блокируется), считается только расстояние
от разрыва до края цели: полный урон внутри `inner`, ноль за `outer` (м): мягкие 8/30,
лёгкая броня 4/15, тяжёлая 1,5/5. Краснополь ×0,85. 100 HP, урон ±20 %. Поэтому
попадание одинаково и в 30 км в пустом чанке InfMap.

## Очки

Цели (их `score`) + первый выстрел после получения цели (<25 м 150, <75 м 100, <150 м 50)
+ расход (до 200, если задача выполнена) + время от цели до первого поражения (до 200)
+ марш (до 100) − 50 за каждый снаряд сверх БК. Оценка по доле от максимума:
S ≥ 90 %, A ≥ 75, B ≥ 55, C ≥ 35. В авто не выше A, при провале не выше C.

## Связь с другими частями

- Хуки ядра: `SkyOps.Arty.SPGFired`, `SkyOps.Arty.ShellImpact` (возвращаем nil, взрыв ядра
  остаётся), `SkyOps.Arty.ShellRemoved`; `shell.data.mission`, `shell.data.missionShot`.
- **Ждём от модуля дрона**: `hook.Run( "SkyOps.Arty.TargetSent", drone, worldPos, err_m, ply )`
  на «передать». Без него работает захват камерой.
- net `skyops_arty_target` задание тоже шлёт (координаты штаба и дрона) в формате модуля дрона (PR #6): `Float x, Float y, Float z, Float err_m, Entity drone`. Хук `SkyOps.Arty.TargetSent` есть в PR #6.
- Карта планшета: оборачиваем `PaintTarget` у панели `SkyOpsArtyMap` (ОП, район поиска,
  точка цели, в авто — сами цели). Файлы `arty/ui` не трогаем.
- Свои хуки: `SkyOps.Arty.MissionStart( run )`, `SkyOps.Arty.MissionStage( run, stage )`,
  `SkyOps.Arty.MissionEnd( run, debrief )`; клиент `SkyOps.Arty.MissionState( state )`.
- net: `skyops_artym_state`, `skyops_artym_msg`, `skyops_artym_debrief` (S→C),
  `skyops_artym_req` (C→S: `menu`, `sync`, `start`, `join`, `leave`, `abort`), `skyops_artym_menu`.

## Команды

| Команда | Что делает |
|---|---|
| `skyops_arty_missions` | меню (клиент), клавиша `skyops_arty_key_missions` (F7) |
| `skyops_arty_mission_start <raid\|recon\|laser\|fleeting> <near\|mid\|far> [марш 1/0] [техника 0/1]` | начать |
| `skyops_arty_mission_abort` | прервать и убрать цели |
| `skyops_arty_mission_status` | состояние (админу и координаты целей) |
| `skyops_arty_mission_reveal` | отладка: штаб сразу даёт цель |
| `skyops_arty_mission_skip` | отладка: пропустить марш и развёртывание |
| `skyops_arty_mission_simhit <dx> <dy> [he\|krasnopol]` | отладка: разрыв в dx, dy м от центра цели без выстрела |
| `skyops_arty_mission_history` | последние результаты |
| `skyops_arty_mission_debrief` | снова открыть итоги (клиент) |
| `skyops_arty_mission_hq_delay`, `skyops_arty_mission_refine` | convar'ы: задержка штаба, сужение района поиска |
| `skyops_arty_mission_hud` | клиент: HUD вкл/выкл |
