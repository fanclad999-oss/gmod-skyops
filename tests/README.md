# Тесты аддона без игры

Код аддона проверяется в обычном LuaJIT: функции GMod подменены заглушками
(`tests/lib/gmod.lua`), рельеф Кировского подменён функцией `KIR.MeshHeight`, а время идёт
кадрами по 1/66 с через хук `Think`. Игра и Steam не нужны.

## Запуск

```sh
sudo apt-get install luajit lua-check   # один раз; luacheck можно и через luarocks
luajit tests/run.lua                    # все тесты
luajit tests/run.lua grid               # только файлы спек, где есть «grid»
TRACE=1 luajit tests/run.lua            # со стеком для упавших
tests/lint.sh                           # luacheck
```

`SKYOPS_ROOT=/путь/к/аддону` проверяет другую копию аддона (папку, где лежит `lua/`).

В GitHub Actions то же самое запускает `.github/workflows/lua-tests.yml` на каждый push и
pull request, который меняет `lua/` или `tests/`.

## Что проверяется

| Файл | Что |
|---|---|
| `spec/loader_spec.lua` | autorun грузит все файлы на сервере и клиенте без ошибок; нет обращений к неизвестным глобалам; sh_ уходят клиенту; все файлы компилируются |
| `spec/grid_spec.lua` | сетка: мир ↔ координаты, север и восток, тысячные ↔ yaw, Direction, квадрат и улитка, границы карты |
| `spec/firecomp_spec.lua` | вычислитель: дальности зарядов, каждое решение перелетается в 3D (промах < 1 м), монотонность прицела, угломер, ошибки, BestCharge, кэш |
| `spec/ballistics_spec.lua` | живые снаряды кадрами Think: падение у цели, время полёта, timescale, холм, Краснополь с пустым Steer, хуки, взрыв, рассеивание |
| `spec/spg_spec.lua` | 2S35 целиком на заглушке LVS-танка: автонаводка → развёртывание → наводка башни → перехват сток-выстрела → разрыв у цели; ручная наводка стрелками; заряды |
| `spec/ui_api_spec.lua` | интерфейс считает то же, что сервер: координаты, квадраты, углы, угломер, решение, дальности зарядов, наводка ствола; поправки «правее/дальше»; запасной расчёт |

Если файла модуля на ветке ещё нет, его группа тестов помечается `skip`, а не падает.

## Ограничения заглушек

- `continue` из GLua препроцессор заменяет на пустой оператор: файлы с ним грузятся, но
  поведение таких циклов тесты не проверяют.
- Клиентские библиотеки отрисовки (`surface`, `draw`, `vgui` и т. д.) — «чёрные дыры»:
  любой вызов проходит. Тесты интерфейса проверяют расчёты `cl_api.lua`, а не отрисовку.
- Корпус САУ в заглушке стоит ровно; наклон на склоне и настоящая модель 2S35 не
  моделируются. Это проверяется только в игре.
- Линтер пропускает любые константы вида `KEY_*`, `FCVAR_*` и т. п., даже несуществующие.

## Новый тест

Файл `tests/spec/<имя>_spec.lua` получает `gm` (заглушки) и `T` (раннер):

```lua
local gm, T = ...

T.describe( "что-то", function()
	T.it( "делает то-то", function()
		gm.reset( "server" )            -- или "client"
		gm.loadDirs( { "skyops/core/", "skyops/arty/core/" } )
		T.near( SkyOps.Arty.Grid.UPM(), 52.49, 1e-9 )
	end )
end )
```
